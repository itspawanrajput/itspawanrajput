## 🏦 What I Build at Work

> Production **conversational banking assistant** for a large financial-services client (details under NDA).

- 🧭 **Agent orchestration** — LangGraph pipeline that routes each turn through intent detection, tool calls to banking APIs, and response generation
- 🛡️ **LLM guardrails** — LLM-based safety/intent classifier with deterministic overrides for high-risk cases; changes gated by an offline **eval harness** with baselines
- 📚 **RAG** — knowledge-base retrieval with prompts and corpora managed in the database, not hard-coded
- ⚡ **Real-time UX** — FastAPI backend with WebSocket streaming, Angular frontend
- ☁️ **Cloud** — AWS Bedrock (Claude models), ECS, DynamoDB, CloudFront
